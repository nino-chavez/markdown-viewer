Use Markdown Viewer as an app

Install on your Mac

Open this website in Google Chrome, then choose Install app in the viewer. If Chrome does not show the install prompt, use its menu: Cast, save, and share → Install page as app.

Open files from Finder

After installing in Chrome, right-click a .md file in Finder and choose Open With → Markdown Viewer. Approve Chrome’s file-opening prompt when it appears.

To use it for every .md file, choose Get Info → Open with → Markdown Viewer → Change All. This is optional. Other Markdown extensions can be assigned separately.

Read offline

Wait for Ready for offline reading in the sidebar before going offline. The app saves its own code and icons on this Mac. Your document contents, images, and file handles stay in memory and clear when the window closes or reloads.

Opening a Markdown file does not grant access to nearby images. Use Open folder or Add images to select them. Browser installation and Finder file handling are supported in desktop Chrome; other browsers can use Open file.

Download the standalone HTML viewer as an offline backup.
