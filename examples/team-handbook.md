# Team handbook

A shared place for the small things that help a team work well.

## Working together

Write decisions down. Give each task an owner. Leave enough context for the next person.

## A useful week

| When | What | Leave with |
| --- | --- | --- |
| Monday | Plan the week | A short list of priorities |
| Wednesday | Share progress | Answers to open questions |
| Friday | Wrap up | Notes for next week |

## Before a handoff

- [x] Explain what changed
- [x] Link to the supporting document
- [ ] Name the next step

> A good note saves someone else a meeting.

## Naming files

Use a name that tells the reader what is inside.

```text
team-handbook.md
meeting-notes.md
release-checklist.md
```
